形式ごとの圧縮方法

画像：解像度・画質を調整して指定容量を目指します。
PDF：各ページを画像として再構成するため、文字検索・リンク・フォーム等が失われる場合があります。
Excel / Word / PowerPoint：ファイル内部の画像を縮小・再圧縮し、文書構造はできるだけ保持します。画像が少ないファイルはあまり小さくならない場合があります。
その他：元形式のまま縮小できないため、ZIP圧縮ファイルとして出力します。

重要：すべてのファイルを必ず指定容量以下にできるわけではありません。すでに圧縮済みの動画・ZIP・Office文書などは削減幅が小さい場合があります。
